chord2tab

rechord-compatible chord text → rational time model (L0), chord slot analysis (L0.5), a voicing solver + idiomatic library (L1), and ASCII tab from fingerpicking patterns (L2), and Karplus-Strong audio (§6) — press Play. From SPEC.md.

Time is exact rational (1/3 never rounds). Chord types are applied as left-to-right operators, not dictionary lookups — see SPEC.md §3.2.
